# McCabe-Thiele ML

Predicting the number of stages and the feed stage of a binary distillation column
from design parameters, using machine learning trained on synthetic McCabe-Thiele data.

## Data
- Synthetic: 5000 samples generated by my own McCabe-Thiele implementation (random seed 42)
- Inputs: alpha, R, xF, xD, xB, plus engineered inv_R, inv_alpha, interactions
- Targets: number of stages (5 to 40), feed stage (2 to 17)

## Current results (linear regression baseline)
Metrics are on the 20% held-out test set (1000 rows).

| Target | Train R² | Test R² | Test RMSE |
|---|---|---|---|
| Number of stages | 0.84 | 0.84 | 1.50 |
| Feed stage | 0.69 | 0.71 | 0.87 |

## Limitations
- Synthetic data, constant relative volatility, saturated liquid feed (q=1)
- Only one model so far: linear regression, which can only represent linear
  relationships. Train and test R² are nearly equal for both targets, which suggests
  underfitting (high bias) rather than overfitting. Predictions also vary a lot for the
  same true value: for example, cases with an actual stage count of 12 (51 test rows)
  were predicted anywhere from 9.4 to 16.5.
- Feed stage R² (0.71) is lower than stage count R² (0.84), likely because the feed
  stage has a narrower spread (std 1.60 vs 3.73), so its RMSE is a larger share of
  that spread (0.54 vs 0.40).
